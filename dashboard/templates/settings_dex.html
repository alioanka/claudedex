📖 DEX Module Guide

What this module does

The DEX module scans DexScreener pairs across EVM chains, scores candidates (volume/liquidity, safety filters, optional ML ensemble), opens spot positions through on-chain swaps, and manages exits via stop-loss / take-profit and a DB-first exit watchdog. It runs as its own subprocess (DEX_MODULE_ENABLED=true in .env) and logs to logs/dex_trading/.

Key knobs (defaults → what to consider)

Key (tab)DefaultNotes
trading.min_vol_liq_ratio (Trading)0.05 Minimum 24h-volume/liquidity ratio to allow a pair into scoring. Blocks ghost pools; active pairs typically run 0.1–1.0. Raising it trades fewer, higher-conviction entries.
trading.max_trades_per_day (Trading)seeded per mig 095 Hard daily entry cap; the engine stops opening once hit.
trading.chain_weights (Trading)seeded JSON Relative scan/entry weighting per chain. Zero a chain to skip it without disabling its RPC pool.
risk_management.stop_loss_pct (Risk)seeded Position SL, read at position-manage time — changes apply to new evaluations without a restart.
risk_management.take_profit_pct (Risk)seeded Position TP, same read path as SL.
ml_models.ml_retrain_enabled (ML)true Auto-retrain loop. Needs 50+ closed trades (ml_retrain_min_trades); interval ml_retrain_interval_hours (24), window ml_retrain_days (90). Until an ensemble exists the engine scores with heuristic_fallback.
ml_models.ensemble_version (ML)— Written by scripts/train_ensemble.py; shown in the banner on the ML tab.

Going LIVE safely

  1. Run in DRY_RUN (the default) until the stats on Performance look sane over multiple days.
  2. Flip dry_run=false for the module (Control Center → DEX → Go-LIVE, or /config/dex_config) and restart the subprocess.
  3. LIVE broadcasts are gated fail-closed: RiskManager.validate_trade, the global kill-switch (logs/.killswitch) and the module pause flag (logs/.pause_dex) are all checked at the broadcast boundary. The exit watchdog auto-closes only in DRY_RUN; LIVE closes go through the on-chain sell path.
  4. Emergency stop: the red sidebar button writes the kill-switch that every module polls.
