Deploy & Use Guide

What each module does, how to shadow-run it, where to read its output, and how to go live safely. The dashboard itself runs standalone on port 8080 — no trading module needs to be running for any page here to work.

The universal workflow (applies to every module)
  1. Enable: set the module's *_MODULE_ENABLED=true flag in .env, then run python main.py (each module is an independent subprocess) — or use the per-module controls under Modules / Control Center.
  2. Shadow-run: every module starts safe by default — trading modules in DRY_RUN, shadow-first modules with shadow_mode=true and live_execution_enabled=false. Let it run for days; nothing touches capital.
  3. Read its panel: trading modules have their own dashboards (sidebar); Intelligence & Ops modules have data panels under Intelligence & Ops (/module/<name>). Empty tables just mean the module hasn't produced output yet.
  4. Tune: every knob of every module is editable with inline documentation at All Settings. Changes are typed-validated, audited in config_history, and re-read for confirmation.
  5. Approve advice: advisory layers (meta controller, regime allocator, param tuner, copy discovery) never act alone — review and approve their proposals at Proposals.
  6. Go live (deliberately): flip the LIVE-gating keys — marked LIVE-GATING in settings — only after reviewing shadow results. Typical pairs: dry_run=false, or shadow_mode=false and live_execution_enabled=true. The UI requires an explicit confirmation for these keys.
  7. Stop instantly: the red EMERGENCY STOP button (every page) writes logs/.killswitch, which every module polls; per-module Pause writes logs/.pause_<module>. Both are honored inside the engines via should_skip_live().
Health ports: dashboard 8080, trading modules 8081-8089, meta controller 8090, Intelligence & Ops 8091-8105. Deeper docs live under docs/ and each module's CLAUDE.md in the repo (optional reading — this page is self-contained).

Safety primitives (memorize these)
  • logs/.killswitch — global stop. Written by EMERGENCY STOP or scripts/emergency_stop.py; polled by every module.
  • logs/.pause_<module> — per-module pause flag (short engine key, e.g. .pause_futures, .pause_stat_arb).
  • DRY_RUN / shadow_mode — per-module simulation modes; the safe default everywhere.
  • RiskManager.validate_trade / FuturesRiskManager.validate_new_position — pre-broadcast gates inside the engines; the dashboard never bypasses them.
  • No advisory module (meta controller, sentinel, regime allocator, param tuner, advisor) can ever place a trade — at most they write pause files or propose config changes you approve.
