Min Confidence

Default: 0.35

Recommended: 0.30–0.50 — live LLM scores cluster around 0.35–0.50.

Advice below this threshold is computed but not published to the DB, dashboard, or Telegram.

Sim Auto-Open

Default: off

When enabled every published advice automatically opens a $sim_default_amount_usd dry-run position. Good for backtesting signal quality. Turn off if you only want the dashboard overview.

Advisor Telegram Bot (separate)

Create a NEW Telegram bot via @BotFather. Add the token as ADVISOR_TELEGRAM_BOT_TOKEN in Secure Credentials. Add your chat or group ID as ADVISOR_TELEGRAM_CHAT_ID. This is a completely different bot from the trading module bot.

The daily digest sends one message per market with that day's short/mid/long advice at the configured advisor_telegram_digest_hour. De-dup logic prevents re-sending the same advice ID twice.

Kronos Weights

Download weights once: python -c "from huggingface_hub import snapshot_download; snapshot_download('NeoQuasar/Kronos-mini', local_dir='/data/kronos/Kronos-mini')"

Set ADVISOR_KRONOS_WEIGHTS_PATH=/data/kronos/Kronos-mini in .env. Then enable via the toggle above. Kronos returns None if weights are missing — the advice cycle always continues.

Activation Checklist
  1. Set ADVISOR_ANTHROPIC_API_KEY in Secure Credentials.
  2. Set ADVISOR_MODULE_ENABLED=true in .env.
  3. Optionally set Telegram bot token + chat ID in Secure Credentials.
  4. Restart the dashboard subprocess from Module Control.
  5. Check logs/advisor/advisor.log for the first advice cycle.
