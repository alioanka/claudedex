Scoring Methodology

Composite score is bounded 0..100 and blends five normalised components (default weights, configurable via config_settings.copytrading_config.leader_score_weights):
  • PnL (35%) — sigmoid of 30d realized USD PnL (mid $500, span $750).
  • Sharpe (25%) — daily-bucketed PnL Sharpe, annualised sqrt(365).
  • Hit Rate (15%) — Bayesian-shrunk closed-trade ratio (Beta(10, 10) prior so a 1-for-1 wallet cannot top a 100-for-200 wallet).
  • Hold (10%) — bell curve maxed at ~6h hold; penalises scalps + bag-holders.
  • Drawdown (15%) — 1 - max_DD on cumulative-PnL curve.
Composite is then shrunk by min(1, trade_count_30d / 20) so low-sample leaders cannot game the rank. Kelly fraction is computed from the shrunk hit-rate and capped at 0.25 (quarter-Kelly), matching core/decision_maker.py:712. Source feeds (DexScreener, Helius, Birdeye, GMGN, on-chain) are tagged per row so operators can weight feeds they trust. See docs/agents/reports/COPY_TRADING_quant.md for the full audit.
